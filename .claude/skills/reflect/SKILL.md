2. For each, propose the smallest edit to a skill, an agent file or CLAUDE.md that would have prevented it. Show the exact text change.
3. Wait for the user's OK before applying any edit. Apply only the approved ones.
4. Update docs/progress.md (dated log line), docs/decisions.md and docs/known-issues.md.
