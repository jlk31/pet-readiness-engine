# Decisions

- 2026-11-27: Money stored as integer pence. Avoids float rounding in the engine.
- 2026-11-27: `supabase/seed.json` is the single source of seed data; `seed.sql` is generated (`npm run seed:sql`).
- 2026-11-27: Artifact preview is a single self-contained HTML file built by `scripts/preview.mjs` (the artifact CSP blocks other hosts, so fonts and art must be inlined there).
- 2026-11-27: Emergency what-if: insured pets pay a flat £150 excess; uninsured pay the full bill inflated to the chosen year.
- 2026-11-28: All Supabase calls are server-side, so session cookies are httpOnly. Only the publishable key is used.
- 2026-11-28: Postcodes encrypted with AES-256-GCM in the app, bound to the owner's id.
- 2026-11-28: Login rate limiting lives in Postgres (`hit_rate_limit`), because server-side calls hide the user's IP from Supabase's own limits.
- 2026-11-28: Work is run Omega-style: Opus orchestrates, Haiku/Sonnet agents do the work, every brief has a "Done when:" check.

- 2026-11-28: Illustration assets come from two MIT-licensed Iconify sets, both open source and free to use: Fluent Emoji (Microsoft, `@iconify-json/fluent-emoji`, https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE) for species art, and Phosphor (`@iconify-json/ph`, https://github.com/phosphor-icons/core/blob/main/LICENSE) for UI duotone icons. `scripts/gen-art.mjs` (`npm run art`) builds `lib/art.ts` from them: `SPECIES_ART` as data URIs and `ICONS` as raw SVG bodies that inherit currentColor.
- 2026-11-28: Anti-AI-look rules (from sinton.agency, Fountain Institute and MindStudio articles; Medium blocked): no emoji or icon decorating headings; no em dashes; no buzzwords or vague CTAs ("seamless", "unlock", "effortless", "Get started"); no blue/purple gradients, neon, aurora glows, rainbow side tabs, decorative status dots; no cards nested in cards; no copy-paste 3-column icon feature grids; even spacing scale; WCAG AA contrast; real meta description and Open Graph tags; buttons say what happens next.
- 2026-11-28: Species art switched from Fluent Emoji (emoji as illustration reads as AI-made) to single-colour silhouettes from game-icons.net via `@iconify-json/game-icons`, licence CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/), authors Lorc, Delapouite and contributors (the Iconify package only names "GameIcons"; per-icon authors are on game-icons.net). Attribution is required, so it is credited in the page footer (`components/Simulator.tsx`) and in `lib/art.ts`. Icons used: cat, sitting-dog, rabbit, rat, parrot-head, gecko, tropical-fish, paw-print. `SPECIES_ART` entries are `{body,w,h}` like `ICONS` and drawn with the mask-based `Icon`. `@iconify-json/fluent-emoji` removed. Phosphor (MIT) stays, regular weight, for two control icons only (house on the home toggle, file-text on the resume button); no icons beside headings.
- 2026-11-28: Design scale: two radii (`rounded-card` .75rem, `rounded-control` .5rem, tokens in `app/globals.css`), spacing in 4/6/8/12 steps for layout, no hover lift, no float animation, no gradients or glows. Pet-card dot replaced by a 24px line swatch in the chart colour (it is the chart legend). Inner boxes inside cards (species picks, breakdown rows, vet list) are rows split by `border-line` hairlines.
- 2026-11-28: `/api/product` returns the product image as a `data:` URI (PNG/JPEG/WebP/GIF/AVIF, max 1 MB, never SVG), fetched server-side through `safeFetch`. The CSP's `img-src` already allows `data:`, so no shop host is added to `proxy.ts`. Fetch failures for blocked and unreachable hosts both give the same 502, so the endpoint can't be used to probe internal DNS names.
- 2026-11-28: A map always shows. With `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` (real app only) the Google map stays as is. Without a key, and always in the artifact preview (its CSP blocks Google's script and other hosts), `components/RegionMap.tsx` draws an inline SVG UK map with no external requests, themed by the colour tokens. Boundaries are the ONS Open Geography Portal "Regions (December 2025) EN BUC" and "Countries (December 2025) UK BUC" layers (ultra-generalised), licence Open Government Licence v3.0, credited in the footer ("Contains National Statistics and OS data &copy; Crown copyright and database right 2026") and README. `node scripts/gen-uk-map.mjs` downloads them with curl, simplifies with `npx mapshaper` (generation time only, not in package.json; topology-preserving Douglas-Peucker, 500 m, islands under 300 km2 dropped, England country layer dropped because the 9 regions cover it) and writes `lib/uk-map.ts` (~34 KB): path data per region, a label point per region, and an equirectangular projection (x scaled by cos 54.5 deg) with `toXY`/`toLatLon`. Clicking a region gives the exact point (real app: same Postcodes.io reverse lookup and vet search as the Google map; preview: sets the region only). The two checks `process.env.NEXT_PUBLIC_PREVIEW` / key sit inline in `Simulator.tsx` so esbuild folds them and no Google URL reaches the preview. Changing the region select clears the pin.
